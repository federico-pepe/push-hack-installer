Push Hack

Are you sure you want to install push-hack on your Ableton Push?

This software is not approved, endorsed, or supported by Ableton. Use it at your own risk.

Back up your sets, files, and samples before installing. Read Ableton's official recovery methods for Push 3 Standalone in case you need to restore your device.

You must uninstall push-hack before any Push software update, then reinstall it after. Make sure Push is on the latest software version before installing for the first time.

This app creates an SSH key just for push-hack. It doesn't touch any other keys on this computer, and you can remove it from Push at any time.

If you run into problems, don't contact Ableton Support — join the Push Hack Discord for help.
