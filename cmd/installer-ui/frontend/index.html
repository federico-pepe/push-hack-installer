Are you sure you want to install push-hack on your Ableton Push?

This software is not approved, endorsed, or supported by Ableton. It's built by a community with the help of AI assisted coding tools. Use it at your own risk.

Before installing: back up your sets, files, and samples. Read Ableton's official recovery methods for Push 3 Standalone in case you need to restore your device.

Please be aware that you must uninstall Push Hack before any Push software update, then reinstall it after. Because of that, make sure Push is on the latest software version before installing Push Hack for the first time.

This app creates an SSH key just for push-hack. It doesn't touch any other keys on this computer, and you can remove it from Push at any time.

If you run into problems, don't contact Ableton Support — join the Push Hack Discord for help.
